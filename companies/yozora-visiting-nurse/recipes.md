# パーソナライズ レシピ: よぞら訪問看護ステーション

対象: 看護師（正職員・求人ID 750939）のみ。

## 当ステーションの特色（パーソナライズで使える素材）

- がん末期・自宅看取りの支援が多い（緩和ケア・ターミナルケア・がん看護の経験が活きる）
- 0歳から100歳までが対象で、小児・精神科の訪問もある（小児科・精神科の経験が活きる）
- 介護保険・医療保険の利用者様が各5割（医療処置の経験も、生活を支える視点も活きる）
- 担当制ではなく「チーム制」で利用者様を支える（病棟でのチーム看護・報連相の経験が活きる）
- 「夜も安心して越せるように」丁寧な看護を届けたいという思いが名前の由来（利用者様に寄り添ってきた姿勢が活きる）

## 共通ルール

- 書き出し: 「プロフィール」「拝見し」は使わない（テンプレ冒頭段落「この度は、プロフィールを拝見し、」と重複するため）
- 冒頭段落の「ご経験やお人柄」「地域医療・ケアにマッチ」、直後の「訪看を基礎から一緒に学んで」「仲間」と同じ言い回しを使わない
- 文字数: 初回 80〜120文字 / 再送 100〜140文字
- 締めは接点・期待の文（「〜と感じています」等）で止める。見学・面談への誘いはテンプレ末尾が担うので書かない
- テンプレ本文にある条件（土日休み・希望休、想定年収、残業1日15分以下、記録・休憩の在宅、直行直帰、オンコール週1回、訪問約5件、2ヶ月の同行、独り立ち1年、チーム制、電動自転車、引越し支援金）を重ねない
- 年収・給与の数字は書かない（出典ごとに数字が違うため。hearing.md #2）
- 地理情報（所在地・訪問エリア）はテンプレートに書いていないが、パーソナライズでも触れない
- 年齢・世代への言及禁止（「〇代」「若手」「ベテラン」等）
- 経験年数の記載ルール:
  - 1〜2年: 書かない
  - 3年: 30代前半以下なら書く、30代後半以上なら書かない
  - 4年以上: 書く
- 「感銘を受けました」「心を動かされました」は使わない
- 上から目線の排除（「フォローします」「安心してください」「しっかり教えます」）
- 送り手の感情主体（「ご一緒したい」「想いを強く感じ」）は避け、相手へのオファー主体で
- ですます調で統一。体言止めや「〜とのこと、」で文を切らない
- 記号（♪◎˖✧）や「！」は使わない（テンプレ本文は明るい文体だが、パーソナライズ文は落ち着いた文で書く）
- 憶測を書かない。不要な前置き（「現在離職中とのこと」等）を書かない
- 居住地に言及する場合は広域表現に留める

## 教育体制（当ステーション固有 — 他社の制度を混ぜないこと）

- 4か月間のプリセプター制度
- 約2か月は先輩が同行訪問（テンプレ本文に記載済み）
- 単独訪問になってからも電話・チャットで相談でき、訪問後の振り返りがある
- 経験に合わせた疾患から担当する
- 完全な独り立ちは1年後が目標（テンプレ本文に記載済み）
- オンコールは入職後3〜4か月後から。独り立ちまでは先輩も一緒に待機
- 研修費用補助、キャリアアップ補助制度

## 型はめパターン

情報が少ない候補者（経歴・自己PRなし）に使用する。
特色バリエーションは候補者ごとにローテーションし、同じ文の連続を防ぐ。
サーバー登録時は match_rules を空にし、サーバー側の年齢×経験年数の判定（経験10年以上かつ35歳以上→型A、経験10年以上で35歳未満→型B1 など）に任せる。経験6〜9年の候補者に型A（「10年以上」）が当たらないようにするため。

### 型A: 豊富な経験への期待

対象: 経験10年以上（35歳以上）

```
10年以上にわたり看護師として歩んでこられたご経験に、強く惹かれました。{特色}私たちの訪問看護で、豊富な臨床経験に裏打ちされたアセスメント力が大きな力になると感じています。
```

特色バリエーション:
- がん末期や在宅での看取りに向き合う機会が多い
- 0歳から100歳まで、小児や精神科の利用者様にも関わる
- 医療保険と介護保険の利用者様が半々の

### 型B1: 確かな経験×特色

対象: 経験6〜9年（経験10年以上で35歳未満もここ）

```
看護師として{N}年にわたり、患者様と向き合ってこられた歩みに注目しました。{特色}私たちの訪問看護で、その積み重ねが自然と活きると感じています。
```

特色バリエーション:
- がん末期・在宅看取りの支援が多い
- 小児から高齢の方まで、幅広い利用者様に関わる
- チーム制で利用者様一人ひとりを支える

### 型B2: 経験×特色

対象: 経験3〜5年

```
看護師として{N}年、臨床の場で積み重ねてこられたご経験に注目しました。{特色}私たちの訪問看護でも、その力が活きる場面が多いと感じています。
```

特色バリエーション:
- 医療保険の利用者様が半数を占め、医療処置にも向き合う
- 0歳から100歳まで、幅広い疾患の利用者様に関わる
- チーム制で情報を共有しながら利用者様を支える

### 型C: 経験とのフィット

対象: 35歳以上 × 経験1〜2年
注意: 応募要件（臨床経験3年以上）を満たさない層。送るかは PM 判断（hearing.md #4）

```
看護師として臨床に携わってこられたご経験に、注目しました。{特色}私たちの訪問看護でも、そのご経験を活かしていただける場面があると感じています。
```

特色バリエーション:
- 利用者様の暮らしに寄り添うことを大切にしている
- 介護保険の利用者様が半数を占め、生活を支える視点が求められる
- チーム制で相談し合いながら訪問に取り組める

### 型D: 経験ある前提で評価

対象: 35歳以上 × 経験未入力
注意: 教育体制の訴求は上から目線になるため使わない

就業中:
```
現在も臨床の現場で患者様と向き合っておられるご経験に、注目しました。{特色}私たちの訪問看護でも、大きく活きる場面が多いと感じています。
```

離職中:
```
看護師として歩んでこられたこれまでの積み重ねに、注目しました。{特色}私たちの訪問看護で、活かしていただける場面が多いと感じています。
```

特色バリエーション:
- 0歳から100歳まで、幅広い利用者様の暮らしに寄り添う
- がん末期や在宅看取りの支援にも向き合う
- チーム制で利用者様を支える

### 型E: ポテンシャル+教育体制

対象: 35歳未満 × 経験1〜2年
注意: 応募要件（臨床経験3年以上）を満たさない層。送るかは PM 判断（hearing.md #4）

```
看護師として臨床の現場で積んでこられたご経験に、注目しました。当ステーションには4か月間のプリセプター制度や訪問後の振り返りがあり、その力を訪問看護へと広げていただける環境です。
```

### 型F: 教育体制+成長環境

対象: 35歳未満 × 経験未入力

就業中:
```
現在も看護師として臨床の現場でご活躍されている力は、訪問看護でも十分に活かしていただけます。当ステーションには4か月間のプリセプター制度があり、単独訪問になってからも電話やチャットで相談できる体制です。
```

離職中:
```
看護師としてのご経験は、訪問看護でも活かしていただけるものです。当ステーションには4か月間のプリセプター制度があり、訪問後には振り返りの時間も設けています。
```

### 型G: 教育体制メイン

対象: 在学中
注意: 応募要件（臨床経験3年以上）を満たさない層。送るかは PM 判断（hearing.md #4）

```
これからの看護のキャリアを考えるなかで、訪問看護も選択肢の一つに加えていただけたらと考えています。当ステーションには4か月間のプリセプター制度や訪問後の振り返りがあり、学びながら訪問看護に取り組める環境です。
```

## 資格修飾（複数資格がある場合、型の文の前に付け足す）

サーバーでは資格の組み合わせが一致すると、型はめ文の**前に**この一文が付く（差し替えではない）。そのため短い一文で完結させ、型の文と重なる言い回し（「私たちの訪問看護」「0歳から100歳まで」等）を避ける。

### 看護師 + 保健師

```
保健師の資格もお持ちで、予防の視点から利用者様の暮らしを捉えられることも大きな強みです。
```

### 看護師 + ケアマネジャー（介護支援専門員）

```
ケアマネジャーの資格もお持ちで、医療と介護の両面から利用者様を捉えられることも大きな強みです。
```

## AI生成パス用ガイド

経歴・自己PRに実質的な情報がある候補者に使用する。

### 生成手順

1. 候補者の経歴・自己PRから最も強い接点を1つ選ぶ
   - 経験年数が4年以上の候補者には、パーソナライズ文中に具体的な経験年数を含めること（例: 「10年以上の臨床経験」「5年にわたる〜」）
2. 上記「当ステーションの特色」から対応する強みを選ぶ
3. 接点を2文・80〜120文字で表現する

### 経歴別の接点対応表

| 候補者の経験 | 対応するステーション特色 | 接点の方向性 |
|------------|----------------------|------------|
| 緩和ケア・ターミナルケア・がん看護 | がん末期・自宅看取りの支援が多い | 「がんの患者様に向き合ってこられたご経験は、在宅での看取りを支える場面で深く活きる」 |
| 小児科・NICU・小児病棟 | 0歳からの小児の訪問がある | 「小児看護のご経験は、お子さまのご自宅に伺う場面で活きる」 |
| 精神科・心療内科 | 精神科の訪問がある | 「精神科で培われた関わり方は、精神科の利用者様の暮らしを支える場面で活きる」 |
| 急性期病棟・内科系病棟 | 医療保険の利用者様が半数 | 「急性期で培われた観察力や医療処置の経験は、医療ニーズの高い利用者様を支える場面で活きる」 |
| 介護施設・老健・特養 | 介護保険の利用者様が半数 | 「生活の場で看護をしてこられたご経験は、ご自宅での暮らしを支える訪問看護で活きる」 |
| 訪問看護 | チーム制で利用者様を支える | 「訪問看護のご経験は、チームで利用者様を支える当ステーションですぐに力になる」 |
| 複数診療科 | 0歳から100歳まで幅広く対応 | 「幅広い診療科のご経験は、多様な利用者様を訪問する当ステーションで活きる」 |

### NGパターン

- 運転免許・自転車など弱い接点で文を構成する
- 会社情報を羅列するだけで接点になっていない
- 地理的要素のみに頼る
- 年収・オンコール・休日などテンプレ本文にある条件を重ねる
- 候補者の希望職種が看護師以外でも、看護師としての接点で書く（希望職種には言及しない）
