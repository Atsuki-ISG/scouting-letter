# パーソナライズ レシピ: 野村病院

## 共通ルール（全職種共通）

- 書き出し: 「プロフィール/ご経歴を拝見し」は使わない（テンプレ冒頭の「ご経歴を拝見し」と重複するため）
- 文字数: 初回 約100〜180文字 / 再送 120〜180文字
- トーン: お手紙の感覚で丁寧に。観察・断定（「〜と考えております」）で閉じない
- 締め方はテンプレ系統で変える（2026-09 のテンプレ差し替えで系統が2つに分かれたため）:

  | テンプレ系統 | 対象 | パーソナライズ文の締め |
  |---|---|---|
  | プレミアムスカウト型 | 看護師正社員・薬剤師パート | AI生成パスは招待調で締めない。「〜と感じています。」等の一段反応で止める。テンプレ側に「ざっくばらんにお話ししませんか？」「お気軽に『話を聞きたい！』とご返信ください」の2つのCTAがあり、招待を重ねると3回続く |
  | 募集要項概要型 | 看護師パート・管理栄養士 | 招待調（「ぜひ一度お話しできましたら嬉しく思います」）で締める。テンプレの締めが「ご返信いただけますと幸いです」のみで面談への誘いがないため、パーソナライズ側が招待を担う |

  ※ 他社はテンプレ末尾に「お話する機会を〜」のCTAがある構成なので、他社のルールをそのまま持ち込まない
  ※ **未対応**: 看護師の型はめパターン（型A〜G）は全て招待調で終わる文言のまま。正社員テンプレに当たると招待が3回続く。パターン側を系統別に分けるか、テンプレ側のCTAを1つに減らすかは PM 判断（`hearing.md` 参照）。サーバのパターンシートも同時変更が必要なため本コミットでは据え置き
- 呼称の使い分け: 施設形態の呼称は「当院」が正（「当ステーション」「当施設」は不可）。パーソナライズ文の接点・評価の文では「私たちの病院」で同じ地平に立つ。制度・環境を事実として紹介する文（型E〜G等）では「当院では〜」も可。テンプレ固定文は「当院」
- 直後の固定段落との重複を避ける:
  - プレミアムスカウト型: 直後が「中途入職者が持つ多様な背景や看護観（仕事観）を理解し、個々のレベルに応じたサポート」の段落。「サポート体制」「多様な背景を受け入れる」を接点の核にしない
  - 募集要項概要型: 直後の理念ブロックが「患者様との対話と日々の関わりの積み重ね」を必ず述べる。接点で「対話」を核にする場合は「声に耳を傾ける」「関わり方」等に言い換える
- 「大変心強く拝見しました」のような装飾副詞付き観察調は避ける。「強く惹かれました」「感じています」等の控えめな一段反応で
- 地理情報（勤務地）はテンプレートに記載済みのため言及しない
- 年齢・世代への言及禁止（「〇代」「若手」「ベテラン」等）
- 経験年数の記載ルール:
  - 1〜2年: 書かない
  - 3年: 30代前半以下なら書く、30代後半以上なら書かない
  - 4年以上: 書く
- 「感銘を受けました」「心を動かされました」は使わない（AI生成だと白々しい）
- こだわり条件は参考程度。資格・経験で接点が作れるなら言及不要
- 上から目線の排除（「フォローします」「安心してください」「基礎を固めてこられた」）
- 送り手の感情主体（「ご一緒したい」「想いを強く感じ」）は避け、相手へのオファー主体で
- ですます調で統一。体言止めや「〜とのこと、」で文を切らない
- 憶測を書かない（「〜されたいのですね」「長く続けているはず」）
- 不要な前置きを書かない（「現在離職中とのこと」「新たな環境でとお考えの〜」）
- 居住地に言及する場合は広域表現に留める（「〇〇市」→「山口県内」）
- 堅苦しい敬語禁止（「拝察いたします」「敬意を表します」等）

- 未経験OK — 管理栄養士資格があれば業務経験不問
- 残業ほぼなし、夜勤なし（日勤のみ）
- 賞与年2回・計3ヶ月分
- マイカー通勤可（通勤手当あり）

### 共通ルール（管理栄養士）

- 書き出し: テンプレート冒頭に「ご経歴を拝見し」があるため「拝見し」以外で開始する
- 文字数: 初回 約100〜180文字 / 再送 120〜180文字
- 地理情報（勤務地）はテンプレートに記載済みのため言及しない
- 年齢・世代への言及禁止
- 産休代替・契約期間には触れない
- 看護師求人の情報を混ぜない
- 上から目線の排除
- ですます調で統一。体言止めや「〜とのこと、」で文を切らない
- 憶測を書かない
- 不要な前置きを書かない
- 居住地に言及する場合は広域表現に留める
- 堅苦しい敬語禁止

### 型はめパターン（管理栄養士）

情報が少ない候補者（経歴・自己PRなし）に使用する。

#### 型A: 病院・施設での栄養管理経験あり

対象: 経歴に病院・施設での栄養管理経験がある

```
病院での栄養管理業務に携わってこられたご経験に、注目しました。精神科医療を提供する私たちの病院で、大いに活かしていただけると感じています。{特色}ぜひ一度お話しできましたら嬉しく思います。
```

特色バリエーション:
- 残業もほぼなく、日勤のみで安定した働き方ができる環境です。
- 日勤のみの勤務で、生活リズムを保ちながらご活躍いただける環境です。

#### 型B: 栄養管理の実務経験あり（病院以外）

対象: 給食センター・保育園・介護施設等での経験

```
管理栄養士として培ってこられた栄養管理のスキルに、注目しました。{特色}私たちの病院で、活かしていただけると感じています。ぜひ一度お話しできましたら嬉しく思います。
```

特色バリエーション:
- 精神科医療を通じて患者様の心と体を支える
- 栄養管理・材料管理・衛生管理を幅広く担う

#### 型C: 経験未入力・経験浅め

対象: 経歴の記載がない / 経験が浅い

就業中:
```
管理栄養士として現場で培われているスキルは、私たちの病院の栄養管理業務で活かしていただけると感じています。残業もほぼなく、日勤のみの環境でご活躍いただけます。ぜひ一度お話しできましたら嬉しく思います。
```

離職中:
```
管理栄養士の資格を活かせるポジションのご案内です。私たちの病院では業務経験を問わず、残業もほぼなく日勤のみの環境で無理なく取り組んでいただけます。ぜひ一度お話しできましたら嬉しく思います。
```

### AI生成パス用ガイド（管理栄養士）

経歴・自己PRに実質的な情報がある候補者に使用する。

#### 生成手順

1. 候補者の経歴・自己PRから最も強い接点を1つ選ぶ
2. 上記「当院の特色」から対応する強みを選ぶ
3. 接点を100文字程度で表現し、「感じています。ぜひ一度お話しできましたら嬉しく思います」で招待調に閉じる

#### 経歴別の接点対応表

| 候補者の経験 | 対応する当院の特色 | 接点の方向性 |
|------------|------------------|------------|
| 病院での栄養管理 | 精神科病院での栄養管理 | 「病院での栄養管理経験は、私たちの現場でそのまま活かしていただける」 |
| 施設・介護系の栄養管理 | 未経験OK | 「施設で培われた栄養管理のスキルは、病院の現場でも十分に発揮いただける」 |
| 給食管理・大量調理 | 材料管理・衛生管理 | 「大量調理で培われたマネジメント力は、私たちの栄養管理で大きな強みになる」 |
| 栄養指導 | 心と体の両面からのケア | 「栄養指導のご経験は、心と体の両面から患者様を支える私たちの栄養管理で活きる」 |
| ワークライフバランス重視 | 残業ほぼなし・夜勤なし | 「日勤のみ・残業ほぼなしの環境で、安定した働き方が可能です」 |
