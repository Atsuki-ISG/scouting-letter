# パーソナライズ レシピ: 東京国際歯科 六本木

## 共通ルール（全職種）

- 挿入位置: テンプレ3段落目の先頭。直後に固定文「これまでのご経験を、予防に特化した当院の環境でさらに発展させ、衛生士としてより高く羽ばたいていただきたいと期待しております！」が続く
- 構成: 2文。1文目＝経験への注目、2文目＝その経験が当院のどの場面で活きるか
- 直後の固定文と重なる「さらに発展」「羽ばたく」「期待しております」は書かない
- 直前の段落と重なる「丁寧な患者様対応」「専門性」「予防医療の方向性とマッチ」は書かない
- 書き出し: 「プロフィール」「拝見し」以外で開始する
- 文字数: 80〜120文字（再送は100〜140文字）
- 口調: 支給文に合わせて「注目しております」「感じております」で揃える
- テンプレ本文にある条件（17:45退勤・月給・立地・研修制度・外国籍患者の割合）は重ねない
- 年齢・世代への言及禁止（「〇代」「若手」「ベテラン」等）
- 経験年数の記載ルール:
  - 1〜2年: 書かない
  - 3年: 30代前半以下なら書く、30代後半以上なら書かない
  - 4年以上: 書く
- 歯科衛生士の資格への言及は不要（保有前提）
- 上から目線の排除（「しっかり教えます」「安心してください」等）
- 堅苦しい敬語禁止（「拝察いたします」「敬意を表します」等）

## 歯科衛生士

### 当院の特色（歯科衛生士向け）

- 1枠60分のアポイント制が基本（保険30〜60分／自費メインテナンス・GBT 60〜90分／ホワイトニング・デンタルエステ60〜75分）
- 患者担当制、歯科衛生士の専用ユニットあり
- 口腔内リスク評価・生活習慣とセルフケアの確認・行動変容支援まで担う
- 北欧式の予防・歯周治療（院長はスウェーデン・イエテボリ大学院で学び、公認歯周病専門医・公認歯内療法専門医）
- 外国籍の患者様が過半数のグローバルな環境
- 自費7割・保険3割、チェア4台すべて個室、全室マイクロスコープ完備
- 理念「歯を生涯にわたって維持管理していける歯科医院」

### 教育体制（歯科衛生士固有 — 他社の制度を混ぜないこと）

- 社内研修制度、資格取得支援制度、セミナー参加費補助
- 法人として研修会を運営している
- 求人票に「GBTメインテナンスの経験が浅くても、学びたい意欲がある方は大歓迎」と明記

### 型はめパターン（歯科衛生士）

#### 型A: 豊富な経験への期待

対象: 経験10年+

```
10年以上にわたり歯科衛生士として多くの患者様の口腔内を支えてこられたご経験に、注目しております。{特色}当院で、その積み重ねが大きな力になると感じております。
```

特色バリエーション:
- 1枠60分のアポイントで患者様一人ひとりのメインテナンスにじっくり向き合える
- 口腔内リスク評価から行動変容支援まで、予防に腰を据えて取り組める
- 患者担当制で、長く患者様の口腔の健康を見守っていける

#### 型B1: 確かな経験×特色

対象: 経験6〜9年

```
{N}年にわたり歯科衛生士として積み重ねてこられた臨床経験に、注目しております。{特色}当院で、そのご経験が活きる場面は多いと感じております。
```

特色バリエーション:
- SRP・SPTからGBTによるメインテナンスまで、1枠60分で取り組める
- 患者担当制で、予防処置から歯周治療まで一貫して関われる
- 北欧式の歯周治療・予防歯科を軸にした

#### 型B2: 経験×特色

対象: 経験3〜5年

```
歯科衛生士として{N}年、臨床で磨いてこられたスキルに注目しております。{特色}当院の診療スタイルと、相性が良いと感じております。
```

特色バリエーション:
- 1枠60分で患者様一人ひとりと向き合える
- 口腔内リスク評価やセルフケア指導にじっくり時間をかけられる
- 北欧式の予防・歯周治療に取り組む

#### 型C: 経験とのフィット

対象: 40代〜 × 経験1〜2年

```
歯科衛生士として臨床に携わってこられたご経験に、注目しております。{特色}当院で、そのご経験が活きると感じております。
```

特色バリエーション:
- 1枠60分のゆとりあるアポイントで予防に専念できる
- 患者担当制で一人ひとりの患者様とじっくり向き合える
- 予防処置からホワイトニング・デンタルエステまで幅広く携われる

#### 型D: 経験ある前提で評価

対象: 40代〜 × 経験未入力
注意: 教育体制の訴求は上から目線になるため使わない

就業中:
```
現在も歯科衛生士として現場に立たれているご経験に、注目しております。{特色}当院で、そのご経験が大きく活きると感じております。
```

離職中:
```
歯科衛生士としてこれまで歩まれてきたご経験に、注目しております。{特色}当院で、再び力を発揮していただける場面が多いと感じております。
```

特色バリエーション:
- 1枠60分のアポイントで患者様一人ひとりと向き合える
- 予防処置からメインテナンスまで担当制で関われる
- 口腔内リスク評価から行動変容支援まで、予防に腰を据えて取り組める

#### 型E: ポテンシャル+成長環境

対象: 20〜30代 × 経験1〜2年

```
歯科衛生士として臨床の現場で積んでこられたご経験に、注目しております。1枠60分のアポイントで予防処置やメインテナンスにじっくり取り組める当院は、技術を深めたい時期にぴったりの環境だと感じております。
```

```
現在も歯科衛生士として現場に立たれているご経験に、注目しております。北欧式の予防・歯周治療に1枠60分で取り組む当院で、そのご経験が活きる場面は多いと感じております。
```

## NGパターン

- 外国籍患者の割合（6割・7割）を書く（クライアント確認待ち）
- 歯科医師・受付/歯科助手の条件（院長候補、独立支援、月給21万円〜 等）を混ぜる
- 「英語が話せなくても大丈夫」など、クライアントが言っていない条件を書く
- 経歴にない業務（SRP、GBT、ホワイトニング等）を経験したかのように書く
- 地理的要素・退勤時間・給与だけで接点を作る（テンプレに記載済み）
- 「さらに発展」「羽ばたく」「期待しております」（直後の固定文と重複）
- ブランクの理由や家庭状況を推測する
