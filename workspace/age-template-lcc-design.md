# 年代別テンプレート設計案（LCCパイロット）

作成: 2026-07-10 ／ 前提となる要件は `memory/project_age_based_templates.md` 参照。
リサーチは一次資料ベースで実施し、引用統計は出典PDFに当たって数値照合済み。

## 1. 結論: 推奨区分は「10歳刻み」ではなく4区分

| 区分 | 呼び名 | 帯の性格 |
|---|---|---|
| 25〜34歳 | キャリア選び直し帯 | 「他の職場への興味」全年代ピーク。結婚・転居が重なる |
| 35〜44歳 | 両立帯 | 「子育て」が退職理由1位。両立支援・勤務時間の重視ピーク |
| 45〜54歳 | 条件・経験承認帯 | 子育て収束。勤務時間・給与・通勤の条件重視が最高水準 |
| 55歳〜 | 無理なく長く帯 | 体力・親の介護・定年が主題。求職市場では最も「動く」層 |
| （〜24歳・年齢不明） | フォールバック | 既存の汎用テンプレをそのまま使う |

10歳刻み（20代/30代/40代/50代）を推奨しない理由:

- 看護師の退職理由は「結婚（25-29歳ピーク）」と「子育て（35-44歳の長い山）」の**2つの波**で動く。第1子出産の平均年齢が31.0歳まで上がった結果、子育ての山は30代後半〜40代前半にあり、「30代」で切ると両立帯を分断し、「40代」で切ると子育て帯と条件重視帯を混ぜてしまう
- 「20代=若手」も不正確。24歳以下はメンタル・適性不安のリアリティショック帯、25-29歳はキャリア選び直し帯で、心理構造が全く違う。ただしLCCは臨床経験3年以上が応募要件（profile.md:99）なので24歳以下はほぼ送信対象外 → フォールバックで足りる

ユーザー仮説「25-35歳のような区切りもあり」はデータと整合した（25-34歳が実際に1つの塊）。

## 2. 根拠データ（年代別の退職理由・重視条件）

一次資料の核は日本看護協会 中央ナースセンター「2024年度 ナースセンター登録データに基づく分析報告書」（就業中求職者 n=30,531 の退職したい理由を年齢9区分でクロス集計。2023年度分 n=32,425 でも同じ構造が再現）。
https://www.nurse-center.net/nccs/scontents/NCCS/html/pdf/2024/202_2.pdf

| 年齢帯 | 退職したい理由の上位（%） |
|---|---|
| 〜24歳 | 精神的健康21.7／適性・能力への不安17.6／興味17.0 |
| 25-29歳 | **他の職場への興味21.2（全年代最高）**／転居13.4／**結婚11.5（全年代ピーク）**／夜勤の負担10.7 |
| 30-34歳 | 興味20.0／子育て15.4／転居12.2／夜勤10.7 |
| 35-39歳 | **子育て18.7（1位に逆転）**／家事と両立しない7.8／妊娠・出産6.8 |
| 40-44歳 | **子育て18.9（全年代ピーク）**／興味18.3 |
| 45-49歳 | 興味15.4／子育て14.8（減衰開始） |
| 50-54歳 | 興味14.9／身体的健康・子育て各8.6 |
| 55-59歳 | 興味10.7／**親族の健康・介護10.2**／身体的健康8.6 |
| 60歳〜 | **定年31.2**／親族の健康・介護8.8 |

就職時の重視条件（同報告書 図8, n=68,724）:

- 「勤務時間」は35歳以上で2割超（ピーク40-44歳25.7%）、24歳以下は9.9%
- 「給与」は50代が最高（50-54歳20.8%・55-59歳21.6%）、24歳以下13.9%が最低。**「給与重視は若手」という通説は逆**
- 「子育てと仕事の両立支援」は30-44歳に集中（ピーク35-39歳14.2%）、50代以上はほぼ0%
- 「キャリアアップ支援」は24歳以下7.0%のみ高く、25歳以上は2〜3%に急減。**「若手=キャリアアップ訴求」も25歳以上には効かない**

市場構造（同報告書 図5・図10）: ナースセンター求職者は60歳以上が最多層（13,499人）で、求職就職率も60歳以上18.2%・50-54歳13.9%が最高。**50代以上は「動きが多く、決まりやすい」層**。LCCの返信実績（後述）とも整合する。

補助データ:

- 厚労省「看護職員就業状況等実態調査」(2010-11): 離職中割合は30代と55歳以降の二山。復職者の職場選び理由は通勤56.5%・勤務時間51.0%で給与10.8%・教育3.5%を圧倒（復職層=通勤・時間が最優先）
- 厚労省 令和4年衛生行政報告例: 就業看護師の50歳以上は約30%
- エス・エム・エス調査2024 (n=19,878、転職サイト系): 転職先候補は20代=病院82.1%、50代=介護施設62.1%に逆転

## 3. 区分ごとの訴求設計（LCC素材マッピング）

大原則（変更なし）: 文面に年齢・年代は一切出さない（templates.md:21、criteria A1）。変えるのは訴求軸のみ。属性の決めつけ禁止（「子育て中とのこと」NG→制度の事実提示）。固定事実（給与額・オンコール条件・募集要項・CTA・署名）は年代間で共通。

### 25-34歳「キャリア選び直し帯」

- 心理: 今の職場が嫌というより「他の道への興味」。結婚・転居のタイミング。夜勤の負担も上位。29歳以下は給与を最重視
- 骨格: **訪看キャリア訴求のメイン帯**。「病棟で身につけた臨床力を、次のキャリアとしての在宅で」という選び直しの物語
- LCC素材: 教育ステーション指定＋9割未経験スタート＋同行1ヶ月（未経験でも移れる根拠）／基本給281,000〜514,000円・インセンティブ非依存（給与軸）／夜勤なし9-18時／大病院内サテライト（病棟との連続性）
- NG: 「キャリアアップ支援」の押し出し（データ上25歳以上には響かない。「学べる」より「選べる・移れる」）

### 35-44歳「時間の再設計帯」

**設計指示（2026-07-10ユーザー）: 子育て世代に嬉しい内容は歓迎だが、ターゲットを子育て世代のみに絞らない。広く取る。** 文面全体が「子育て世代専用」に読めたら失敗。独身・子なし・男性が読んでも自分向けと感じることが基準。

- 心理: 勤務時間の重視が全年代ピーク（40-44歳25.7%）。夜勤・残業を含む働き方そのものを見直したい時期。「生活との折り合い」の中身（子育て・介護・自分の時間・学び直し）は人それぞれ
- 骨格: 誰にとっても意味がある「時間が読める働き方」を傘に。日勤のみ9-18時／残業ほぼなし／有給消化率ほぼ100%／急な休みに柔軟／通勤: 港区・渋谷区・千代田区の半径5km圏。その傘の下で「生活のかたちは人それぞれ」の広い枠を示す
- 子育て系事実（産休育休実績・時短・オンコール免除・週1〜パート・子育て中のスタッフ在籍）は子育て世代に嬉しい事実として自然に見せてよい（隠さない）。ただし「ライフスタイルに合わせて選べる」枠の中の具体例として置き、ヘッダー・冒頭の主役は時間系事実
- 訪看訴求: 「夜勤のない働き方に移る」文脈で自然に接続
- 実績: 30歳の返信者が産休後入職可否を質問（history/conversations/02755659.yml）— 関心を持つ人は制度列挙から自分で拾う、の実例として
- 注意: 「子育てママ多数活躍中」（profile.md:75）は使うなら中立形へ変換（「子育て中のスタッフも在籍」）し一言まで

### 45-54歳「条件・経験承認帯」

- 心理: 子育て収束、条件重視（勤務時間・給与・通勤）が全年代で最高。教育押しは上から目線（recipes.md:101 で確立済み）
- 骨格: 経験の正当評価＋条件の明快な提示。基本給上限514,000円（経験を給与で評価する構造）／20代〜50代の幅広い世代在籍／通勤・エリア
- 訪看訴求: 「キャリア」より「病棟経験がそのまま強みになる」承認の形（急性期→医療依存度の高い在宅ケア等、good-scout-pro.md:961-975の橋渡し表）
- 不足素材: 平均年齢・離職率の実数（人間関係・定着の訴求に必要）→ ヒアリング事項

### 55歳〜「無理なく長く帯」

- 心理: 体力・親の介護・定年。市場では最も動きが活発で決まりやすい
- 骨格: 無理なく長く働ける具体性。日勤のみ／訪問5件前後/日／残業ほぼなし／オンコール免除可能（2026-07-10ユーザー確認済み・LCCは記載どおり）／50代在籍実績。教育系ブロックは丸ごと外す（good-scout-pro.md:1290-1294）
- 実績: 58歳の返信者が「無理なく長く臨床に集中できる環境」を重視し、訪問件数・オンコール・記録業務・給与レンジを具体的に質問（history/conversations/00540173.yml）＝この帯の関心そのもの
- 不足素材: 定年・再雇用制度の有無が profile.md に無い → ヒアリング事項（60代送信there年齢ゲート確認も含む）

## 3.5 帯別スタイル仕様（2026-07-10ユーザー指示: 細かい表現も帯で変える）

既存のトーン3種（casual/business/letter、good-scout-pro.md:1468-1480）を帯に紐付ける。LCCのブランドトーン「親しみやすくフランク」（templates.md:11）の幅の中で調整し、逸脱しない。ツマミは4つのみ:

| 帯 | 文長・テンポ | 丁寧度 | 装飾記号・感嘆符 | 締めの温度 |
|---|---|---|---|---|
| 25-34 | 短め・軽快 | フランク寄り（casual） | 「！」1〜2個・見出し記号OK | 誘う（〜しませんか？） |
| 35-44 | 中庸 | フランクと丁寧の中間 | 控えめ（0〜1個） | 誘う・軽く |
| 45-54 | 簡潔・数字主導 | ビジネス調（business） | ゼロ | 委ねる（お知らせください） |
| 55+ | ゆったり・一文を丁寧に | お手紙調（letter） | ゼロ・盛らない | 委ねる・静か（ご無理のない形で） |

根拠: 55歳返信者が装飾・具体度過剰を「AIで書いているようだ」と指摘した実例（LCC examples.md:14-20）。上の帯ほど盛らない文体が信頼になる。文面に年代語を出さない原則はスタイルにも適用（「お若い方向けの」等の説明語も当然NG）。

## 3.6 下半分フォーマット（2026-07-10 競作で確定・ユーザー承認済み）

「募集要項の条件羅列は面白くない」というユーザー指摘を受け、4方式（ベネフィット見出し／一日の流れ／不安先回りQ&A／対比・転換）を競作し、3審査員（候補者心理・品質基準・運用）で採点。**「不安先回りQ&A型」が勝者**（合成版を採用）。

採用フォーマットの構造:
- ヘッダー → 挨拶 → 目的文（帯のフック）→ パーソナライズ挿入 → 評価・面談確約段落 → **＜よくいただくご質問＞（帯別可変レイヤー・Q3〜4問）** → **＜条件の要点＞（8本共通の固定フッター）** → CTA → 署名
- Qの選定が帯の訴求軸を担う。オンコールと移動（辞退最頻要因）は必ずどこかのQで扱う
- 答えを盛らず「面談でご確認ください」と誠実に残す（それ自体が返信動機）
- 給与行は「※夜勤なしでの金額です」フレーム（夜勤を手放すと収入が落ちる恐怖への直接回答）
- オンコールの数字はQ回答内のみ。フッターと二重管理しない（改定時修正1箇所の原則）
- 「よくいただくご質問」は実績ベース（58歳がオンコール・訪問件数、37歳が教育を実際に質問。history/conversations/）

競作で負けた知見（他社展開時の参考）: ①②③ベネフィット見出しは「広告バナーの棚に入れて読み流される」／対比表（夜勤あり→なし）は「営業資料に見えてしらける」＋候補者の現状決めつけリスク／一日の流れ型は読ませる力最強だが帯別差し替えが構造化できず運用に不向き（Q1問に圧縮して吸収済み）。

## 4. 訪看キャリア訴求の事実関係（率直な整理）

**「給与は上がることが多い」はデータで支持されない。** 日本看護協会2024年度賃金調査（一次資料・数値照合済み）:

- 税込月給総額（夜勤手当込み）: 病院382,093円 vs 訪看347,181円。同年代比較では35-39歳で約5.4万円、45-49歳で約7.2万円、病院が高い
- 基本給はほぼ同水準（260,451円 vs 254,476円）。差は夜勤手当
- 賞与: 病院118万円 vs 訪看95万円

→ スカウトで「訪看は給与が上がる」と書くのは捏造リスク。正しい訴求は「**夜勤をなくしても基本給がしっかりしている**」で、LCCは基本給281,000〜514,000円という実額で個別に返せる（ここがLCCの強み。業界一般論は使わない）。

**「20代後半に訪看キャリア訴求」はデータが支持する。**

- 訪看への就業意向は20代が64.6%で全年代最高（JNA2017）なのに、訪看従事者に占める20代は約6%（令和2年衛生行政報告例）＝意向と現実のギャップが最大の層
- 「臨床経験3〜5年が目安」は法令・報酬上の要件ではなく転職メディアの通説。LCCの要件は「概ね3年以上」なので25歳以上なら大半が満たす
- 求人倍率4.54倍（全施設種別で最高）・ステーション数15年連続増で、業界は若手参入促進に舵。「若手こそ歓迎される」は事実ベースで書ける

**不安への先回りが本文の設計図。** 訪看に関心がない理由の最多は「一人で訪問する怖さ・プレッシャー」53.9%、次いで「オンコール対応」44.7%（エス・エム・エス2024, n=19,878）。LCCの回答: 大病院内サテライト（医師・MSWとの物理的距離）＋同行1ヶ月＋9割未経験スタート＋オンコール3〜5回/月・免除可・手当5,000円/回。`knowledge/visiting-nurse-concerns.md` の8論点のうち③オンコール・⑧移動/エリアはprofile.mdで回答可能、①教育の実態・②独り立ちプロセス・④安全配慮・⑤ケース構成は未回収（→ヒアリング）。

## 5. 実装メモ（テンプレ執筆後の作業）

- 対象: 看護師のみ・初回のみ（正社員＋パート）×4区分 = **新規8本**。再送・お気に入り・PT/ST/医療事務は据え置き（既存が使われ続ける）
- テンプレシートの type 命名で対応（例: `正社員_初回_25-34`）。resolver が年齢→区分を解決し、該当typeが無ければ既存 `正社員_初回` にフォールバック。シート構造・管理画面・拡張は変更不要
- 年齢不明・25歳未満 → フォールバック（型はめの「不明→young」規約は流用しない）
- routing.py の age_group は 40s+ 一括（routing.py:62-68）なので流用不可。resolver側で 25/35/45/55 境界の判定を新設
- 効果測定: 送信シートの年齢層バケットが「50歳〜」一括（orchestrator.py:184-205）のため、45-54と55+の返信率を分離できない。`55-59歳`「60歳〜」を追加する小修正を推奨
- 型はめパターン（型A〜G）は当面現行のまま。ただし挿入先の骨格が年代別になるため、区分とパターン文のトーン整合を執筆時に目視確認
- AI生成はテンプレ全文をトーン参照でsystemプロンプトに渡すため、年代テンプレにすればパーソナライズ文もある程度追従する

## 6. LCCヒアリング事項（テンプレ品質に効く順）

既存の未回収リスト（meetings/2026-04-17-info-gaps.md）と重なるものが多い。年代テンプレ執筆前に取れると品質が大きく変わる:

1. 教育ステーション指定の「実態」（研修頻度・指導体制）— 25-34帯の核
2. 同行1ヶ月後の段階的独り立ちプロセス — 25-34帯・一人訪問の怖さへの回答
3. 平均年齢・離職率・勤続年数の実数 — 45-54帯の定着訴求
4. 定年・再雇用制度 — 55+帯
5. オンコールの開始時期・出動手当の実額 — 全帯（55+帯で特に）
6. 看護ケース構成（看取り/精神科/小児の割合）— パーソナライズの橋渡し精度
