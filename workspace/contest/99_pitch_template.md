# ピッチ構造テンプレート「遠景→近景→即実行」

*作成: 2026-05-19*
*用途: コンテスト・ピッチ・社内提案・投資家向け資料の汎用テンプレート*

---

## このテンプレートの本質

**ピッチを「遠景（壮大）→ 近景（具体提案）→ 即実行（リソース活用）」の3段構造で組むことで、ビジョンと現実性を両立させる**

- 遠景だけ: 「絵に描いた餅」と思われる
- 近景だけ: 「儲かりそうな新規事業」止まり、業界変革インパクトが伝わらない
- 3段構造: **「ビジョンで判断したい」と思わせつつ「明日から動ける」も担保**

---

```
               │

               │

```

## win-winメッセージ設計（5方向）

ピッチに必ず組み込むべき「**5方向のwin**」：

| プレイヤー | この事業による Win |
|---|---|
| クライアント企業 | コスト削減・課題解決パートナー |
| エンドユーザー（求職者等） | 個別性・信頼・長期関係 |
| 業界全体 | 構造課題への解決・持続可能化 |
| 自社 | 資産獲得→事業オプション無限化 |
| 株主・投資家（将来） | スケール事業＋複利資産で長期成長 |

→ 「お金儲け」感ゼロ、ビジョンで判断したいと思わせる構造

## 北極星ビジョンの書き方

### 良いビジョンの3要素
1. **業界変革のスケール感**: 「○○業界の構造を変える」
2. **獲得する資産の明示**: 「3資産（A×B×C）を持つ唯一無二」
3. **win-winの強調**: 「業界全体・全プレイヤーが得する未来」

### 悪いビジョンの例
- 「世界一の○○になる」（抽象的すぎる）
- 「売上100億円目指す」（金額のみ、ビジョンなし）
- 「○○を提供する会社」（普通すぎる）

### エニケアの北極星ビジョン例
> 「エニケアは、医療業界の人材データ基盤プレイヤーになる。
> **『優良求人 × 経営母体パイプ × 求職者の信頼』の3つを揃えた唯一無二の存在**として、業界の構造課題（紹介手数料1,139億円・離職率・赤字構造）を根本から変える」

## このテンプレートの強み

1. **代表志向との合致**: ビジョン・現実性・段階展開の全てを1ピッチで
2. **「儲かりそうな新規事業」と一線を画す**: ビジョン先行で本気度伝わる
3. **「具体性とビジョン性の両立」**: どの軸の質問にも答えられる構造
4. **再利用可能**: コンテスト後の社内提案・投資家ピッチ・採用ピッチに転用可

---

## 適用ケース

- **コンテスト用ピッチ**: 案C 採用代行包括RPO、AB統合版 等
- **社内提案**: 新規事業のチーム合意形成
- **投資家ピッチ**: シードラウンド〜シリーズA
- **採用ピッチ**: 経営層・候補者向けの会社説明
- **クライアント営業**: 大型契約獲得のための提案
