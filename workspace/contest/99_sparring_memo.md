## 🌟 全体軸（2-4分・両輪戦略）

### 軸（Why）— 3者全員が機能不全

- **病院**: 経営できてない（赤字61%・手数料812万/施設）
- **求職者**: キャリア設計なし・無策に紹介使いすぎ（離職23.1%）
- **人材紹介会社**: 手数料取るだけで業界変える気ない（1,139億円が10年で2.4倍）

→ **3者ゲームチェンジで、頑張った人が報われる医療業界へ**

### 両輪戦略

- **案C（B2B 完全RPO）**: 病院 + 人材紹介会社側からひっくり返す
- **AB統合版（B2C 本音相談所）**: 求職者側からひっくり返す
- **合算3年目10.5〜14億円**

> **「医療職には選択肢を、施設には自立を。3者ゲームチェンジの両輪」**

## 🛡 想定反論と答えのストック

### 共通・両案

| 反論 | 答え |
|---|---|
| 2案併走は現実的？絞れ | Phase展開で時期ずらす（C案先行・AB1年遅れ）、リソース別アサイン |
| リソース不足では？ | 看護師4名・介護3名・AIエンジニアで分担、外部委託も視野 |
| 利益相反は本当に切れる？ | 別法人格、データ・候補者の分離、契約条項で利害衝突防止 |
| 片方ずつやればよくない？ | 3者全員カバーするには両輪必要、片方だと「ゲームチェンジ」軸が崩れる |
| ブランド分散しない？ | 親会社エニケアの下、2サブブランドで運営、「両輪」を強みとして発信 |

### 案C特化

| 反論 | 答え |
|---|---|
| 1人120万は安すぎ・価格競争 | AI＋拡張で生産性、自社紹介の調達コスト副産物、**業界手数料を下げるのが目的の一部** |
| 4機能は事業の幅広すぎ | Phase設計で段階展開、案①+案⑧の既存検討案を統合してリソース集中 |
| 3年目4.88億は他案より低い | 中央値、強気で8.5億、**粗利率55-67%は他案より高い**、4年目以降の顧問ストック |
| 3年卒業を本当に選ぶか | **オプション**扱いで義務化しない、選ばないクライアントは永続契約 |
| メンタル・定着の提供体制 | 既存看護師4名+介護3名のSME、Lyra/Laudio型の体制設計 |
| 採用5名で粗利率61%は本当？ | **複数施設兼任モデル**前提（1人で3-5施設見れる、Chrome拡張あるから） |

### AB統合版特化

| 反論 | 答え |
|---|---|
| 「キッカケCRモデル」は看護師業界で再現できる？ | 看護インフルエンサー多数存在（ななえる13万・NOE54万等）が誰も紹介と統合してない→ホワイトスペース |
| 個人ブランド依存リスク | 看護師4名から1名選抜・複数キャラ運用、人物固定化リスク分散 |
| B2C立ち上げに時間かかる | 1-2年は赤字許容、SNS（TikTok/Instagram）主軸で6-12ヶ月で軌道 |
