## 2. 各案の本質的な構造

### ① 早期離職スコア+定着支援サブスク（78点）

**コア仮説**: 採用紹介料1人90-200万円を1年で離職されたら大損 → 月3-5万円の定着支援サブスクで回収できる

**市場規模・追い風**:
- 看護師離職率11.0%（既卒1年内17.9%）、介護職12.4%
- 紹介手数料: 看護師平均159万円、介護福祉士89万円
- 紹介市場の医療費圧迫は10年で2.4倍・1,000億円超 → 業界・厚労省が依存度下げたい
- TAM約269億円/年（56,000施設×月4万×12）

**競合状況**:
- HR OnBoard、Wevox、ミキワメ、HRBrain、タレントパレット、SmartHR、Refcome、HiManager
- 「医療×早期離職予測×現場マネ介入×月3-5万」は誰も取っていない
- 米国Laudioが医療特化で確立（Nebraska Medicineで1年目看護師離職-47%・年$5.4M削減）

**ホワイトスペース**: **「医療版Laudio」が日本に不在** → 明確な空き

**粗利**: Lite 2.5万/Standard 4万/Pro 7万の3階建てで加重平均56%、足切り余裕クリア

**最大リスク**: HRBrain等の医療特化版参入 → 先行2-3年でブランド代名詞化が勝敗を分ける

**1年目PL**: 既存5施設無料β→ARR 200-500万円、3年目で150施設・ARR 7,200万円

### ② シンママ看護師「教育→紹介」プラットフォーム（85点）

**コア仮説**: シンママ看護師の制約（夜勤NG/送迎/急早退）を一般紹介エージェントが扱いきれない → 教育＋コミュニティ＋厳選紹介の二段ロケット

**市場規模・追い風**:
- 就業看護師120万人×女性91%×ひとり親推計5-8% = シンママ看護師約8万人
- TAM約14万人、SAM 2-3万人、SOM 1,500-3,000人/年商1-2億円
- 2025年4月施行：祝い金禁止＋手数料公表義務化＋上限規制議論 → 業界が「価値提供型紹介」への転換期
- こども家庭庁の重点政策、自治体連携余地

**競合状況**:
- 看護師領域に「教育＋コミュニティ＋紹介」一気通貫の事業者は不在
- 薬剤師領域に既存事例: 「薬キャリmama」「ママ薬PLUS」 → **看護師版は5-10年遅れ**

**ホワイトスペース**: **「薬キャリmamaの看護師版」が日本に不在**

**重要な軌道修正提案**: 「シンママ専門」と看板を狭めるとSAM小さい → 「制約あるママナース全般」に広げて中身でシンママを濃く扱う設計

**粗利**: 月額500人×1,000円（粗利70%）＋紹介月3件×80万円（粗利60%）= 年商3,480万円・粗利2,148万円（粗利率62%）

**最大リスク**: 
1. SAMの絶対サイズ（看板修正で対応）
2. コミュニティ運営の人月コスト（看護師4名ローテ＋動画資産化）
3. 紹介事業許可取得2-3ヶ月（Day1並行）
4. 紹介手数料上限規制（25%上限想定でも対応済）

**1年目PL**: 3,480万円・粗利2,148万円、3年目1-2億円射程

### ③ 看護師副業マッチング（原案40点/ピボット65点）

**コア仮説（原案）**: 医療版タイミーを作る

**市場規模**:
- スポットワーク市場2024年1,216億円（2年で3倍）、2034年予測1.8兆円
- 看護師TAM約3,120億円/年、SOM（5年後1%）9.4億円GMV→売上2.4億円
- 看護師30%超が副業経験、67%が興味あり

**致命的問題**:

1. **規制壁**: 看護師派遣は労働者派遣法で**原則禁止**（例外5つのみ：へき地/産休育休代替/社会福祉施設等への日雇い派遣/紹介予定派遣/訪問入浴）。日雇い派遣は60歳以上/学生/副業として年収500万円以上/世帯500万円以上の主婦のみ → **看護師メイン層（30-50代・本業看護師・主たる生計者）は合法的に日雇い派遣を受けられない**
2. **競合超レッドオーシャン**: カイテク（登録ワーカー50万人、事業所9,000所、売上2年17倍）、タイミー（医療福祉売上+114.6%急成長中、登録1,347万人）、Ucare、ベネッセ、MCナースネット
3. **メルカリハロが1,200万人集めても勝てず2025年12月撤退** → 二面市場のネットワーク効果が壊滅的に難しい実証
4. **粗利30%構造的に困難**: 純PFモデル試算で5年経ってもGMV10億・売上2.5億で固定費回収できず赤字

**ピボット案（65点）**: 「訪問看護スポット応援に特化＋業務委託/短期派遣（31日以上）/紹介予定派遣の3層モデル」
- 大手が手薄なホワイトスペース
- 粗利率40-50%、5年目で売上1.4億・粗利7,000万円
- 神奈川県内ドミナント戦略、ARK/LCC/いちごを需要アンカー

### ④ 厳選紹介+オウンドメディア（73点）

**コア仮説（修正版）**: エンジニア業界のFindy/Forkwell型を看護介護に持ち込む

**重要修正**: ユーザーが言及した「morrow」は調査の結果特定できず（Morrow Worldは英語コーチ、morrow株式会社はマッチングアプリ）。**「医療版Findy」と再フレーミング**するのが正確で伝わりやすい。

**市場規模**:
- 看護師人材紹介市場2,000-3,200億円、介護含めて4,000-5,000億円TAM
- 人材紹介業の典型粗利率90%以上（足切り余裕クリア）
- 紹介手数料: 看護師平均76万円・上限159万円、介護福祉士89.1万円

**競合状況**:
- 看護師オウンドメディア: 看護roo!（月間PV 1,600万・UU 280万・会員80.8万）とナース専科の2強
- 総合領域のSEOで戦うのは無理筋
- 紹介エージェント大手: レバウェル看護、看護のお仕事、ナースではたらこ、マイナビ看護師、ナース人材バンク

**ホワイトスペース**: 
- **「40代ママ復帰特化」「介護管理職特化」「PT/OT特化」「TikTok中心」**が空き
- 看護師TikTok/Instagram爆発的成長中（あやの19.3万、長野じゅりあ100万、看護師なな総9万）

**強力な訴求材料**: 紹介経由の半年離職率23.1%（ハロワ12%の約2倍）= 「定着率訴求」の武器

**粗利**: 紹介業の典型90%粗利、ただし営業/メディア人件費引いて1年目赤字

**最大リスク**:
1. 紹介手数料上限規制（川崎市等9都県市が要望、財務省2025年4月提言）
2. SEOで看護roo!クラスを目指すのは5年以上で実現困難
3. メディア立ち上げ期赤字

**1年目PL**: 売上7,200万円・営業利益▲800〜▲2,800万円（赤字）
**2年目**: 売上2.16億円・営業利益5,000-7,000万円
**3年目**: 売上4.2億円・営業利益1.8億円（利益率42%）

**ピボット**: SEO一本足を諦め、SNS（TikTok/Instagram/YouTube Shorts）主軸＋既存顧客8社＋候補者DB活用なら6-12ヶ月で軌道に乗せ可能

### ⑤ 訪看シフト最適化SaaS（原案51-57点/ピボット80点）

**コア仮説（原案）**: 訪看ステーション向けのシフト＋訪問ルート最適化SaaS

**市場規模・追い風**:
- 全国訪看ステーション18,753（神奈川1,400-1,500社）、年平均成長率8.8%
- 2040年に向け在宅医療需要+43-62%増加見込み
- 訪看師81.9%が超過勤務、神奈川の訪看有効求人倍率3.26倍
- TAM約113億円、SOM現実線2,000-3,000万円ARR

**致命的問題**:

1. **ホワイトスペース既占拠**: ZEST（業界No.1・9.6億円調達・1秒自動生成）、CareMaker（2025-04に1億円調達・シフト自動化済）、カナミックかんたんAI訪問ルート（5万事業所基盤）、iBow + AI訪問計画（電カルNo.1・3,028ステーション）の4強体制
2. **eWeLLが生成AI機能を無償提供**で追加SaaS予算枠を奪取中
3. **B2Bエンタープライズセールス力不足**: SaaS営業マネージャー＋FS×2＋SDR＋CSの最低5名・年間3,000-5,000万円の追加投資必要、ARR 1.2億円事業に対してリターン合わない
4. **電子カルテとの連携必須**: 訪看が欲しいのは「シフト・ルート・記録・請求が一体化」、エニケアの単独SaaSは「もう一つの入力先」として嫌われる
5. **エニケアの最大アセット（候補者DB・採用代行ノウハウ）がほぼ活きない**: SaaS開発・販売との接点が薄い

**ピボット案（80点）**: 「採用×シフト統合プラットフォーム」
- 単体SaaS開発を諦め、ZEST/CareMakerと**再販パートナーシップ**
- エニケアの強み（採用代行）と組み合わせた「採用×シフト×ルート」一気通貫サービス
- 月20-30万円/社で既存8社からアップセル開始
- 採点51-57→80に改善

## 3. クロスカット発見

### A. 「他職種/他国の看護師版」パターンが3案で実証

ユーザーの仮説「他職種であるやつの看護師版とか結構良かったりしそう」は強く支持された：

| 案 | 元ネタ | 看護師版の状況 |
|---|---|---|
| ① 定着支援 | **米国Laudio**（医療特化AI離職予測） | 日本に直系不在 = ホワイトスペース |
| ② シンママ案 | **薬剤師業界の薬キャリmama/ママ薬PLUS** | 看護師版5-10年遅れ |
| ④ 厳選紹介+メディア | **エンジニア業界のFindy/Forkwell/LAPRAS** | 看護業界には総合大手のみ、業界特化ニッチが空き |

→ **次の派生案を出すなら「○○業界で成功しているサービスの看護師版」を10-20個ブレストする価値あり**。元ネタ候補：
- 弁護士向けキャリアエージェント → 看護師版
- 美容師フリーランス支援 → 看護師フリーランス支援
- IT人材の副業ラウンドアップメディア → 看護師版
- ITエンジニアのスキル証明（GitHub）→ 看護師スキル証明
- 教師の年収UP塾 → 看護師の年収UP塾
- など

### B. ホワイトスペースの「狭さ」と「広さ」のトレードオフ

- **② シンママ専門** → SAM小さい → 「ママナース全般」に広げる推奨
- **④ 看護師全般** → 競合大手強い → 「40代ママ復帰特化」「PT/OT特化」「TikTok中心」などに細分化が穴
- ②と④の方向は実は似てきている（細分化されたママナース×新メディア×コミュニティ×紹介）

### C. 統合案の可能性

| 統合パターン | 内容 | 評価 |
|---|---|---|
| **【統合A】②＋④** | 「制約ありナース特化（ママ/シンママ/復職組/40代以上）」のキャリアPF。教育＋メディア＋紹介の3本柱 | **最強候補。両案の弱みを補完** |
| **【統合B】①＋既存RPO** | 既存採用支援にクロスセル。「採用→定着」一気通貫RPO | 自然な拡張、リスク低 |
| **【統合C】③ピボット＋⑤ピボット** | 訪看ステーションの「人と稼働」両方を解決するパッケージ | リソース散漫リスク |

### D. 規制リスクが業界横断的に存在

- ③ 看護師派遣の労働者派遣法・日雇い派遣規制 → 致命的
- ④ 紹介手数料上限規制（川崎市等9都県市が要望、財務省も）→ 中期リスク
- **→ 「紹介に依存しない収益モデル」を持つ①②に間接的な追い風**

### E. エニケアの本質的アセットの確認

5案を横並びで見て、エニケアの強みが効くのは：

1. **既存顧客8社（病院/訪看/介護）** → ①④（クロスセル）、②（求人提供元）、⑤ピボット（営業先）
2. **候補者DB数千-数万件** → ①（教師データ）、②④（CACゼロローンチ）
3. **現役看護師4名＋介護経験者3名** → ②④（コンテンツSME）、①（メンタリング）
4. **SNSマーケ＋動画編集** → ②④（メディア立ち上げ）
5. **AIエンジニア** → ①（スコアリングモデル）

→ **②と④が「全アセットを総動員」できる案。①は「①と⑤の一部以外を眠らせる」案**
