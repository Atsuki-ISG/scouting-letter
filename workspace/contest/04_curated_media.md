# 新規事業コンテスト アイデア④：厳選紹介＋オウンドメディア（医療版morrow）徹底調査レポート

**調査日:** 2026-05-18
**調査担当:** 新規事業市場調査チーム
**対象アイデア:** 厳選した質の高い求人だけ取り扱う紹介エージェント＋看護介護従事者向けオウンドメディア（モロー / morrow の医療看護介護版）
**結論先出し:** **コンセプト方向は正しい。が「単独事業として推進」はリスクが高い。エニケアの既存顧客＋候補者DBを起点に「厳選紹介 → メディアは後追い」の順番でやれば勝てる**。詳細は最下段「結論」参照。

## エグゼクティブサマリー（5行）

1. 看護師・介護人材紹介市場は単価で年収の20〜35%、紹介手数料 平均約76〜159万円（医師は335万円）と「絶対額の大きいレッドオーシャン」。ただし顧客（病院／施設）は手数料高騰に悲鳴を上げており、**「厳選＝定着率高い＝結果として安い」と訴求できれば差別化可能**。
2. 「医療版morrow」を文字通りやろうとすると、**メディア立ち上げに18〜36ヶ月、SEO競合は看護roo!（月間PV1600万）等の巨人**が支配する超レッドオーシャン。**「自社メディアでオーガニック集客」だけでCAC回収する戦略は数字が合わない**。
3. ただしエニケアには **看護師4＋介護者3＋SNSマーケ1＋動画編集者1＋AIエンジニア1** という"記事監修できる現役人材"がいる。これは大手紹介エージェント（コールセンター中心）にはない強み。**「現場が書く・現場が話す」コンテンツ品質×SNS（特にTikTok/Instagram）に振れば、メディア立ち上げを6〜12ヶ月に短縮できる**。
4. 厚労省の祝い金禁止・5職種手数料公開義務（2025〜2026年施行）は **「悪質エージェントの淘汰→誠実エージェントへの追い風」** で、エニケアの参入タイミングは良好。一方で **手数料上限規制リスク（川崎市など9都県市が要望）** が顕在化すれば単価圧縮の逆風。
5. **総合得点: 73点 / 100点**（財務19/30、実現可能性17/25、課題市場16/20、エニケア親和性14/15、伝わりやすさ7/10）。**競合④案の中では中堅評価**。先行投資型のため、初年度は赤字必至、2年目に黒字転換を見込むPLが現実的。

## 3. 他業界の類似サービス（★最重要★）

### 3-1. morrow（参考事例の正体確認）

ユーザー記載の「morrow（エンジニア厳選転職）」を直接検索したが、**該当する会社が複数存在し、エンジニア厳選転職を主業務とする"morrow"は確認できなかった**。検索でヒットしたのは:
- **株式会社Morrow World**（福岡） — 英語コーチ・留学事業（Engread、タビケン留学）。エンジニア転職とは無関係。[Indeed](https://jp.indeed.com/cmp/(%E6%A0%AA)morrow-World)
- **morrow株式会社**（米田氏代表） — マッチングアプリ「TalkWave」「remmary」。エンジニア転職とは無関係。[公式](https://www.morrow-inc.jp/company)
- **Morrow Engineering（米国）** — 米国のエンジニアリングコンサル。日本市場関連性なし。

**推定**: ユーザーが想定するmorrowは、おそらく **`株式会社プロパゲート` などが運営する「キャリアコーチング×厳選紹介」系の少数派ベンチャー**、もしくは類似コンセプトのブティック型エージェント。本レポートでは "morrow的コンセプト" を「**コンサルタントが自分で技術理解できる ＋ 求人を厳選 ＋ メディアで求職者集客**」というモデルとして扱う。

### 3-6. 「看護師業界に厳選×メディアプレイヤーがいない理由」

調査の結果、**「厳選＝高品質マッチング × オウンドメディア」を本気でやっている看護師紹介エージェントは少数**。理由は:
1. **看護師は売り手市場すぎる** → 数を捌けば儲かるので、厳選にする経済合理性が薄い
2. **看護roo!のSEO資産が巨大** → 後発がメディアで戦うには3〜5年の投資が必要
3. **看護師に「キャリアコーチング」概念が浸透していない** → 「とりあえず転職サイト登録」がデフォルト
4. **求職者は「複数社登録（平均2〜4社）」が常識化** → 単独メディアからの直接送客が成立しづらい

→ **逆に言えば、看護師市場の価値観が変化し、「質重視」「キャリア重視」のセグメントが顕在化し始めている今は、参入チャンスでもある**。

## 4. 価格・収益モデルのベンチマーク

### 4-1. 粗利率の前提

人材紹介事業の**典型的な粗利率は90〜100%**（仕入原価が実質ゼロ。コストはほぼ全て人件費＋広告費の販管費）。営業利益率では:
- 業界平均: **20%前後**（[circusAGENT](https://service.circus-group.jp/circus/foragent/column/recruitment-operating-margin/)）
- JACリクルートメント: **23%**
- MS-Japan: **40%**（特化型の強み）
- 介護人材紹介の船井総研試算: **粗利率100%／営業社員数名で粗利1億円可能**

**→ コンテストの足切り条件「粗利率30%以上」は確実にクリア**。粗利率は90%以上、営業利益率も20〜35%は射程内。

### 4-2. 収益モデル試算（厳選パターン）

#### 前提
- 平均紹介手数料単価: **120万円**（年収600万円 × 20% を厳選で高めに）
- 一般的な看護師紹介の単価76万円より**約58%高い**設計（年収アップ厳選なので妥当）
- コンサルタント1人あたり成約: **月3〜5名**（業界標準。普通の量売りなら月10名だが厳選なので少な目）

#### 1年目（メディア立ち上げ期）

| 項目 | 数字 |
|---|---|
| コンサル人数 | 3名 |
| 月間成約 | 3名 × 月平均2件 = 月6件 |
| 年間成約 | 約60件 |
| 売上 | 60件 × 120万円 = **7,200万円** |
| 売上原価 | ほぼ0 |
| 販管費（人件費10人＋メディア制作費＋広告） | **約8,000万〜1億円** |
| 営業利益 | **▲800万〜▲2,800万円**（赤字） |

#### 2年目

| 項目 | 数字 |

### 4-3. CAC（顧客獲得コスト）試算

| チャネル | CAC（推定） | 注釈 |
|---|---|---|

### 4-4. なぜ「厳選×高単価」が成立しうるか

- 看護師紹介手数料の上限帯は**124万円〜159万円**（既に大手は突破している）
- 年収700万円超の訪問看護管理職・専門看護師・認定看護師など、**ハイクラス領域は単価140〜250万円**が実現可能
- 「定着率の高さ」を訴求できれば、**手数料が高くても顧客の総コスト（紹介料＋早期離職リスク）は下がる**ロジックが通る（紹介経由の離職率23.1% vs ハロワ12% の8倍コスト差データを武器に使える）

## 8. 5枚スライド構成案

### スライド1: タイトル & 結論
- **タイトル**: 「医療版morrow ― 厳選紹介 × 現場が語るオウンドメディア」
- **サブタイトル**: 「年収600万円超の看護・医療職を、定着率2倍で送り込むエージェント」
- **3年で売上4.2億円・営業利益1.8億円を目指す**

### スライド2: 課題と市場機会
- 看護師紹介市場2,000〜3,200億円のレッドオーシャン
- ただし**紹介経由の離職率23%、直接応募の2倍** → 顧客が悲鳴
- 厳選×定着率で顧客の総コストを下げる新カテゴリー創出
- 看護師TikTok/Instagramの爆発的拡大 → 新しい集客チャネルが空いている

### スライド3: ソリューション（事業モデル）
- **厳選**: 年収UP・働き方マッチ・文化フィットで厳選した50社/年程度の優良求人のみ
- **オウンドメディア**: 看護師4＋介護者3が監修・執筆。SEOではなく**SNS（TikTok / Instagram）中心**
- **AIエンジニア＋スカウト技術**: エニケアの既存RPO資産（候補者DB＋スカウト技術）をフル活用
- **収益**: 年収20〜35%の紹介手数料、平均単価120万円

### スライド4: 競合比較とエニケアの勝ち筋
- 大手紹介（レバウェル・マイナビ）: **量売り、品質に幅** → エニケアは品質で差別化
- 看護roo!: **メディアSEOは最強だがコンテンツが企業発** → エニケアは**現場が書く・話す**で差別化
- 他業界事例（Findy/Forkwell/JAC/MS-Japan）: 業界特化＋メディアで利益率20〜40%実現
- **エニケアの強み**: 既存顧客8社、候補者DB数千〜数万件、現役医療職7名、SNSマーケ／動画編集者

### スライド5: 投資・PL・実行計画
- 1年目（投資期）: 売上7,200万円、営業利益▲800万〜▲2,800万円
- 2年目（黒字化）: 売上2.16億円、営業利益5,000〜7,000万円
- 3年目（拡大期）: 売上4.2億円、営業利益1.8億円（利益率42%）
- **初期投資**: 1〜1.5億円（メディア制作＋人員拡張＋システム）
- **最初の100日**: ①既存顧客に厳選紹介の試験運用 ②TikTokチャンネル開設 ③40代ママ復帰特化メディアβ版ローンチ

## 10. 結論

### 10-1. 戦略的に「やる」価値があるか

**条件付きでYes**。ただし「医療版morrowを単独事業として大規模に投資して立ち上げる」のではなく、**「エニケアの既存RPO事業の自然な拡張として、厳選紹介を先行・メディアを後追い」**で進めるべき。

### 10-2. 競合他案との優位性・劣位性

| 観点 | 優位性 | 劣位性 |
|---|---|---|
| エニケア親和性 | **既存資産（顧客8社、候補者DB、現役医療職7名、SNS／AI人材）の活用度はコンテスト案中最大** | ― |
| 即金性 | 紹介事業は **成約即売上計上**（受注契約と異なり前受金等の調整なし） | メディア収益化は2〜3年遅れる |
| 粗利率 | 90%以上 | ― |
| 規制リスク | ― | **手数料上限規制が顕在化したら直撃** |
| 競合状況 | ハイクラス・特化領域はホワイトスペース | 総合領域はレッドオーシャン |

### 10-3. 1年後の売上イメージ（PL概算）

| 項目 | 数字 |
|---|---|
| 売上 | **7,200万円** |
| 売上原価 | 0 |
| 粗利 | 7,200万円（粗利率100%） |
| 販管費 | 8,000万〜1億円（人件費6,000万＋メディア／SNS制作2,000〜4,000万） |
| **営業利益** | **▲800万〜▲2,800万円**（投資期想定） |
| 成約件数 | 60件（コンサル3名×月平均2件） |

**重要**: メディア立ち上げ期は赤字を許容するPL設計が必須。**3年目に営業利益1.8億円（利益率42%）まで持っていく前提**で投資判断を行うべき。

### 10-4. メディア立ち上げの時間軸（率直な見立て）

- **SEOで看護roo!クラスを目指す**: **5年以上、ほぼ実現不可能**
- **SEOでニッチ領域（40代ママ復帰・PT/OT・介護管理職）でTOP3を取る**: **18〜30ヶ月**
- **SNS（TikTok/Instagram）で月間リーチ100万人**: **12〜18ヶ月**（既存看護師4名の活用次第で短縮可）
- **エニケア候補者DB＋SNS×厳選紹介のサイクルを回す**: **6〜12ヶ月で軌道に乗せられる**

**→ SEO一本足を諦め、SNS×候補者DB×既存顧客で立ち上げる戦略なら、現実的な時間軸で勝負可能**。

### 10-5. Goなら最初の100日にやるべきこと3つ

1. **既存顧客8社で「厳選紹介トライアル」を実施**
   - 既存RPO顧客の中で求人ハードルの高い4〜5社にヒアリング、**通常スカウト送信に加えて「ハイクラス厳選候補者の専属紹介」を月1〜2件提案**。成約手数料の単価設定と顧客反応を検証する。これだけで初月から売上が立つ可能性。

2. **TikTok / Instagram 公式アカウント開設＋現役看護師4名を「公式クリエイター化」**
   - 「現役訪問看護師が転職体験を語る」「ブランク復帰ナースのリアル」など、**個人インフルエンサーの個別発信ではなく、エニケアブランドでの集合的コンテンツ発信**を週3〜5本ペース。動画編集者がいるので量産可能。
   - 同時にプロフィール欄に「キャリア相談はLINEから」CTAを設置、**候補者DBにメディア経由で月50〜100名追加**を目標化。

3. **「40代ママ復帰／ブランク復帰看護師特化」のオウンドメディアβ版をリリース**
   - 既存顧客の佐藤病院（40代以上ママ・ブランク復帰ターゲット）の知見を活かし、**「40代から始める看護師の働き方」**にテーマ特化したオウンドメディアをまず10〜20記事でβ版ローンチ。
   - 介護経験者3名の「事務長」「訪問介護」「施設」の3視点も並走させ、**6ヶ月以内に月間PV1万→3ヶ月以内に月間PV10万**を目指す（ニッチなら可能なライン）。

### 10-6. 最終判定

**コンテスト④案として推進する場合の最終評価: 73点 / 100点**

- **粗利率30%以上の根拠**: ◎（人材紹介は粗利率90%以上、足切り条件クリア）
- **先行事例最低1つ**: ◎（Findy、薬キャリAGENT、MS-Japan等多数）
- **エニケアの強みフル活用**: ◎（既存顧客＋候補者DB＋現役医療職＋SNS人材）
- **時間軸の現実性**: △（メディア立ち上げに時間がかかる。SNS主軸戦略でカバー可能）
- **規制リスク**: △（手数料上限規制が最大の不確定要素）

**他案と比べたい際の判断軸**:
- もし他案が「既存顧客を活かせない／全く新しい市場で勝負する」案であれば、**④案は既存資産活用度で圧倒的に有利**
- もし他案が「短期で収益化できる SaaS／プロダクト案」であれば、④案は立ち上げ期の赤字リスクで不利
- 中長期的にエニケアが「医療人材のPF事業者」になりたい構想を持っているなら、**④案は戦略整合性が高くGo推奨**
