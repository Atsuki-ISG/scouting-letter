## 3. ベスト戦略案（改訂版）

5案全てが88-92点に到達した結果、**「どれを選んでも勝てる」状態**になった。ペア相手との適性とパッションで選択するのが正解。以下、4つの選択軸：

### 戦略マトリクス（軸別の最適案）

| ペア相手と話したい論点 | 推奨案 |
|---|---|
| **最高スコア・包括＋差別化キャラで勝負したい** | **AB統合版 菩薩エージェント（93点）** |
| 規模感・包括的ビジネスストーリーで勝負したい（菩薩なしで安全に） | 統合案A（92点） |
| 共感・ストーリー・社会的意義で勝負したい | ② シンママ（91点） |
| 即着手・現実解・コンテスト後すぐ動ける案で勝負したい | ④ 医療版Findy（90点） |
| 既存事業強化・財務ストーリーで勝負したい | ① 定着支援（88点） |
| 完全新規市場創造・伝わりやすさで勝負したい | 案8 メンタルケア（88点） |

### AB統合版を選ぶ条件・避ける条件

**選ぶ条件（揃えば93点）**:
- ⓐ 菩薩キャラ候補が看護師4名から1名以上出る前提（Day 1-30で適性評価）
- ⓑ プレゼン力でスライド複雑性をカバーできるプレゼンター
- ⓒ 「お金で動かない菩薩エージェント」キャラが刺さる審査員構成

**避ける条件（揃わなければ統合案A単独に退避）**:
- ペア相手が菩薩キャラに乗らない／別の役割で動きたい
- 「個人ブランド依存リスク」を審査員が強く突いてくる可能性高い
- プレゼン時間が短く5枚スライドで複雑構造を説明しきれない

### 各案の独自価値（差別化ポイント）

- **統合案A**: 「3モデル統合の中長期理想像」。米国Clipboard+Lyra+Incredibleが日本未成熟ゆえに統合で先行
- **②**: 「ママ最深セグメント特化×二段構造で規制完全分散」。統合案Aでは扱いきれない深さ。**統合案Aのサブブランドとしても機能**
- **④**: 「Incredible Healthに純粋特化／Day 30売上化」の現実解。統合案Aの理想像に対する現実解
- **①**: 「規制が来れば構造的拡大」のEXIT実証あり（Hinge IPO等）。既存事業のクロスセルで Day 1 から動ける
- **案8**: 「世界的にも未着手の看護師特化メンタル」で完全新規市場創造。**③20満点・⑤10満点で審査員ばらつき耐性最高**

### 統合・連携の可能性

- **統合案A + ②**: 統合案A＝フラッグシップ、②＝ママ特化サブブランド（共通インフラ：許可・営業・コンテンツ）。1チームでも運営可能
- **統合案A + ①**: 紹介→定着→再紹介の縦串。連動すれば事業規模さらに拡大
- **統合案A + 案8**: 「ナースの仕事」と「ナースの心」の対をなすサービス群。長期では1ブランドに統合可能

### コンテスト提出戦略の候補（更新）

- **(a) 統合案A 単独提出** — 92点で最高、包括ストーリー強い
- **(b) ② 単独提出** — 91点、共感×規制分散で安全
- **(c) ④ 単独提出** — 90点、Day 30売上化の即実行性で説得力
- **(d) ① 単独提出** — 88点、財務最強、既存事業強化の安全策
- **(e) 案8 単独提出** — 88点、伝わりやすさ満点
- **(f) 統合案A + 案8 を準備し当日選択** — リスク分散

→ ペア相手の強み・興味で(a)〜(f)から選ぶ。
